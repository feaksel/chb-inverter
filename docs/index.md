# 5-Level Cascaded H-Bridge Inverter

Modular cascaded H-bridge multilevel inverter built around two single-bridge PCB modules and an STM32 Nucleo-F303RE running phase-shifted carrier PWM.

> **Status (May 2026):** Hardware fabricated and bench-validated. Firmware deployed. Demonstration successful.

This site is the consolidated engineering reference for the project. The site is built from `docs/` in [the repository](https://github.com/feaksel/chb-inverter) and republished on every push to `main`.
